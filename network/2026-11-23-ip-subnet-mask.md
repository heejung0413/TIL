# IP 주소와 서브넷 마스크의 원리

## 한 줄 요약

IP 주소는 **"동네 + 집 번호"** 로 이루어진 주소이고, 서브넷 마스크는 그중 **어디까지가 동네인지** 알려 주는 표시입니다.

---

## 1. IP 주소는 32개의 0과 1

우리가 보는 `192.168.1.10`은 사람이 읽기 쉽게 바꾼 모양이고, 컴퓨터는 **32비트(0과 1이 32개)** 로 봅니다.
8비트씩 4덩어리로 나눠 각각 10진수로 적은 것이 우리가 아는 IP 주소입니다. 한 덩어리는 0~255 사이 값입니다.

```
192      .168      .1        .10
11000000 .10101000 .00000001 .00001010
```

## 2. IP 주소는 "네트워크 부분 + 호스트 부분"

주소에 비유하면 이렇습니다.

| 실제 주소 | IP 주소 |
| --- | --- |
| 서울시 강남구 테헤란로 (동네) | 네트워크 부분 |
| 123번지 (집 번호) | 호스트 부분 |

- **네트워크 부분**: 같은 네트워크(같은 공유기, 같은 사무실 망)에 있는 기기들이 똑같이 가진 앞부분
- **호스트 부분**: 그 네트워크 안에서 기기 하나하나를 구분하는 뒷부분

문제는 IP 주소만 봐서는 **어디까지가 네트워크 부분인지 알 수 없다**는 것입니다. 이걸 알려 주는 것이 서브넷 마스크입니다.

## 3. 서브넷 마스크: "여기까지가 동네" 표시

서브넷 마스크도 32비트입니다. **1이 이어진 곳까지가 네트워크 부분, 0인 곳이 호스트 부분**입니다.
1은 항상 앞에서부터 연속으로 나옵니다.

```
IP 주소      192      .168      .1        .10
             11000000 .10101000 .00000001 .00001010
서브넷 마스크 255      .255      .255      .0
             11111111 .11111111 .11111111 .00000000
             |<------ 네트워크 부분 ------>|<호스트>|
```

`255.255.255.0`은 "앞 24비트가 네트워크, 뒤 8비트가 호스트"라는 뜻입니다.

### CIDR 표기 (`/24`)

1의 개수만 적는 간단한 표기도 많이 씁니다.

| 서브넷 마스크 | CIDR | 의미 |
| --- | --- | --- |
| 255.0.0.0 | /8 | 앞 8비트가 네트워크 |
| 255.255.0.0 | /16 | 앞 16비트가 네트워크 |
| 255.255.255.0 | /24 | 앞 24비트가 네트워크 |
| 255.255.255.192 | /26 | 앞 26비트가 네트워크 |

그래서 `192.168.1.10/24`는 "IP 192.168.1.10, 서브넷 마스크 255.255.255.0"과 같은 말입니다.

## 4. 원리의 핵심: AND 연산

IP 주소와 서브넷 마스크를 비트끼리 **AND** 하면 **네트워크 주소**(동네 이름)가 나옵니다.
AND는 둘 다 1일 때만 1이므로, 마스크가 0인 호스트 부분은 전부 0으로 지워집니다.

```
IP 주소      11000000.10101000.00000001.00001010   (192.168.1.10)
마스크   AND 11111111.11111111.11111111.00000000   (255.255.255.0)
-----------------------------------------------
네트워크 주소 11000000.10101000.00000001.00000000   (192.168.1.0)
```

### 이걸 어디에 쓰나: "같은 동네인가?" 판단

컴퓨터가 데이터를 보낼 때 먼저 하는 일이 이 판단입니다.

1. 내 IP AND 마스크 → 내 네트워크 주소
2. 상대 IP AND 마스크 → 상대 네트워크 주소
3. 둘이 **같으면** 같은 네트워크 → 상대에게 직접 보냄
4. **다르면** 다른 네트워크 → 게이트웨이(공유기·라우터)에 맡김

```
내 PC   192.168.1.10/24 → 192.168.1.0
프린터  192.168.1.50    → 192.168.1.0   같음 → 직접 전송
구글    142.250.207.4   → 142.250.207.0 다름 → 공유기로 보냄
```

택배로 치면 같은 동네면 직접 들고 가고, 다른 동네면 택배 회사(라우터)에 맡기는 것과 같습니다.

## 5. 한 네트워크에 기기를 몇 대 둘 수 있나

호스트 비트가 `h`개면 주소는 `2^h`개이고, 그중 2개는 예약돼 있어 기기에 줄 수 없습니다.

- **네트워크 주소**: 호스트 부분이 전부 0 (예: `192.168.1.0`) → 동네 이름
- **브로드캐스트 주소**: 호스트 부분이 전부 1 (예: `192.168.1.255`) → 동네 전체 방송용

> 사용 가능한 호스트 수 = 2^(32 - CIDR) - 2

| CIDR | 호스트 비트 | 사용 가능한 기기 수 |
| --- | --- | --- |
| /24 | 8 | 2^8 - 2 = 254 |
| /26 | 6 | 2^6 - 2 = 62 |
| /16 | 16 | 2^16 - 2 = 65,534 |

## 6. 서브네팅: 큰 동네를 작은 동네로 나누기

마스크의 1을 늘리면 네트워크를 더 작게 쪼갤 수 있습니다.
`192.168.1.0/24`(254대)를 `/26` 4개로 나누면 이렇게 됩니다.

| 서브넷 | 네트워크 주소 | 기기에 줄 수 있는 범위 | 브로드캐스트 |
| --- | --- | --- | --- |
| 1 | 192.168.1.0 | .1 ~ .62 | .63 |
| 2 | 192.168.1.64 | .65 ~ .126 | .127 |
| 3 | 192.168.1.128 | .129 ~ .190 | .191 |
| 4 | 192.168.1.192 | .193 ~ .254 | .255 |

### 예제: `192.168.1.70/26`은 어느 서브넷인가

`/26` 마스크의 마지막 덩어리는 `11000000` = 192 입니다.

```
70       01000110
192  AND 11000000
---------------
         01000000 = 64
```

→ 네트워크 주소 `192.168.1.64`, 서브넷 2번에 속합니다.

## 7. JavaScript로 계산해 보기

비트 연산자는 JS에도 있습니다. `>>> 0`은 결과를 음수가 아닌 32비트 정수로 맞춰 주는 용도입니다.

```js
const ipToInt = (ip) =>
  ip.split('.').reduce((acc, part) => (acc << 8) + Number(part), 0) >>> 0;

const intToIp = (n) =>
  [24, 16, 8, 0].map((shift) => (n >>> shift) & 255).join('.');

const maskFromCidr = (cidr) => (cidr === 0 ? 0 : (~0 << (32 - cidr)) >>> 0);

function subnetInfo(ip, cidr) {
  const mask = maskFromCidr(cidr);
  const network = (ipToInt(ip) & mask) >>> 0;
  const broadcast = (network | ~mask) >>> 0;
  return {
    mask: intToIp(mask),
    network: intToIp(network),
    broadcast: intToIp(broadcast),
    hosts: cidr >= 31 ? 0 : 2 ** (32 - cidr) - 2,
  };
}

const sameNetwork = (a, b, cidr) => {
  const mask = maskFromCidr(cidr);
  return (ipToInt(a) & mask) === (ipToInt(b) & mask);
};

console.log(subnetInfo('192.168.1.70', 26));
// { mask: '255.255.255.192', network: '192.168.1.64', broadcast: '192.168.1.127', hosts: 62 }

console.log(sameNetwork('192.168.1.10', '192.168.1.50', 24)); // true
console.log(sameNetwork('192.168.1.10', '192.168.2.50', 24)); // false
```

## 8. 내 컴퓨터에서 확인해 보기 (macOS)

```sh
ipconfig getifaddr en0    # 내 IP (Wi-Fi)
ifconfig en0 | grep inet  # netmask 0xffffff00 = 255.255.255.0
netstat -nr | grep default # 게이트웨이(공유기) 주소
```

`0xffffff00`은 서브넷 마스크를 16진수로 쓴 것입니다. `ff`가 255, `00`이 0입니다.

## 참고: 사설 IP 대역

집·회사 내부망에서만 쓰는 주소로, 인터넷에서는 직접 보이지 않습니다.

| 대역 | 흔히 보는 곳 |
| --- | --- |
| 10.0.0.0/8 | 회사·클라우드 내부망 |
| 172.16.0.0/12 | Docker 기본 네트워크 등 |
| 192.168.0.0/16 | 가정용 공유기 |

## 정리

- IP 주소 = 32비트 = **네트워크 부분 + 호스트 부분**
- 서브넷 마스크 = 어디까지가 네트워크 부분인지 표시 (1 = 네트워크, 0 = 호스트)
- **IP AND 마스크 = 네트워크 주소** → 같으면 직접, 다르면 게이트웨이로
- 사용 가능한 기기 수 = 2^(호스트 비트) - 2
- 마스크의 1을 늘리면 네트워크를 잘게 나눌 수 있음 (서브네팅)
